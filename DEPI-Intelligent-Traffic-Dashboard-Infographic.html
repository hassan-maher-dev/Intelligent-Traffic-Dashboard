Overview

Simulates real-time smart-city traffic monitoring: sensor data is collected, processed through containerized microservices, and visualized on a live interactive dashboard.
Core Features
  • Real-time traffic monitoring dashboard
  • Traffic sensor simulator (Collector)
  • Cloud-native deployment on Amazon EKS
  • GitOps continuous deployment (ArgoCD)
  • Prometheus + Grafana observability
  • Alertmanager alerting rules
  • HTTPS access via AWS Load Balancer
